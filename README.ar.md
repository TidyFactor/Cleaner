## 🎯 لماذا TidyFactor/Cleaner؟

> [!IMPORTANT]
> **بيان Cleaner: لماذا تفشل أدوات التنظيف التقليدية مع المطورين**  
> أدوات تنظيف الأقراص المعتادة (مثل CCleaner أو أدوات تنظيف النظام الافتراضية) والسكربتات السطحية (`rm -rf`) تتسبب في كوارث لبيئات المطورين:
> 1. تعجز عن فهم تعاقب إصدارات إضافات المحررات، مما يترك جيجابايت من مجلدات إضافات VS Code المكررة والمهملة.
> 2. تفشل بأخطاء مثل `Access is denied` أو `unlinkat` بمجرد وجود عمليات خلفية نشطة تقفل الملفات (`gopls`, `tsserver`, `intelephense`, `codex-code-mode-host`).
> 3. تحذف قواعد بيانات المتصفحات عشوائياً، مما يدمر تسجيلات الدخول النشطة والـ Cookies وكلمات المرور والمفضلة.
> 4. تتجمد لعدة دقائق متواصلة عند محاولة فحص أشجار مجلدات عميقة مثل `node_modules` أو سجلات `.git`.
> 
> **TidyFactor Cleaner هو الحل الجراحي الآمن المصمم للمطورين:** يعتمد على مسح فوري فائق السرعة عبر الاستثناءات الذكية، وعزل تام لكاش المتصفحات متعددة الحسابات دون مساس بالهويات، وحل منهجي لإقفال العمليات، مع مصفوفة أمان رباعية تحمي نماذج الذكاء الاصطناعي المحلية وأسرار `.env` البرمجية.

| البُعد | الأدوات التقليدية / السكربتات العشوائية | `tidyfactor-cleaner` |
|---|---|---|
| **الفحص التشخيصي** | يتجمد لدقائق أثناء تتبع مجلدات `node_modules` و`.git` العميقة | **فحص فوري في أجزاء من الثانية** عبر روبوكوبي و`find -prune` |
| **إضافات VS Code والمحررات** | تتجاهل مجلدات الإضافات أو تحذف الإضافات المخصصة بالكامل | **إزالة التكرار الدلالي (SemVer)**: الإبقاء على أحدث إصدار وحذف القديم |
| **تنظيف كاش المتصفح** | تدمر ملفات تعريف الارتباط والجلسات وكلمات المرور | **عزل قاطع غير قابل للمساس**: استهداف كاش الويب والـ GPU والأكواد فقط |
| **إقفال العمليات الخلفية** | تفشل بأخطاء الرفض `Access is denied` أو تتوقف بصمت | **كشف رقم العملية (PID) وحلها منهجياً** (`gopls`, `tsserver`, `kilo`) |
| **ذكاء أطر العمل** | تجهل خصوصية ملفات Next.js أو Laravel أو حاويات Docker | **تشغيل الأدوات الرسمية أولاً** (`artisan optimize:clear`, Docker prune) |
| **أمان الذكاء الاصطناعي والأسرار** | تخاطر بحذف أوزان النماذج المحلية أو ملفات التكوين | **المستوى الرابع المحمي**: أوزان `.gguf` و`.safetensors` وأسرار `.env` محصنة تماماً |
| **استهلاك سياق الوكيل الذكي** | تلقي بآلاف الرموز (10k+ Tokens) دفعة واحدة داخل الشات | **موجه أوامر رشيق (`SKILL.md`)** لا يتعدى 350 رمزاً، ويحمّل الذاكرة عند الطلب |

## 🚀 البدء السريع والتثبيت

اختر طريقة التثبيت المناسبة لبيئة عملك:

### الخيار أ: عبر TidyFactor CLI (موصى به)
التثبيت مباشرة داخل مساحة العمل النشطة:
```bash
npx @tidyfactor/cli add cleaner
```
*أو إذا كان الـ CLI مثبتاً عالمياً (`npm i -g @tidyfactor/cli`):*
```bash
tidyfactor add cleaner
```

### الخيار ب: عبر منظومة مهارات الوكلاء المفتوحة (skills.sh / Vercel Labs)
التثبيت للمعيار الموحد لجميع محررات ووكلاء الذكاء الاصطناعي (Cursor, Antigravity, Claude Code, Windsurf, Trae, Codex):
```bash
npx skills add tidyfactor/cleaner
```

### الخيار ج: التشغيل المباشر كحزمة NPM مستقلة
```bash
npx @tidyfactor/cleaner@latest
```

## ⚡ بنية موجه الأوامر الخماسي

تتيح مهارة `tidyfactor-cleaner` **5 أوامر دقيقة ومباشرة** عبر هيكلية توجيه نموذجية:

| الأمر | مقصد المستخدم | الملفات المحملة | القيمة والمخرجات |
|---|---|---|---|
| `brief` / `audit` | "فحص مساحة التخزين" / "أين تذهب المساحة؟" | `workflows/diagnose-storage.md` + `memory/storage-matrix.md` | تشخيص فوري وحساب المساحة القابلة للاستعادة وتقديم خيارات A/B/C/D تفاعلية. |
| `ide` / `vscode` | "تنظيف إضافات VS Code" / "حذف الإضافات القديمة" | `workflows/clean-ide.md` + `memory/lock-matrix.md` | إزالة الإصدارات المتقادمة من الإضافات وتفريغ كاش VSIX وحل إقفال العمليات. |
| `browser` | "تفريغ كاش المتصفح دون فقدان تسجيلات الدخول" | `workflows/clean-browser.md` + `memory/safety-matrix.md` | حذف كاش HTTP وGPU وCode Cache بأمان تام لجميع الحسابات والملفات الشخصية. |
| `devtools` | "تنظيف كاش الحزم" / "تنظيف كاش Next.js أو Laravel" | `workflows/clean-devtools.md` + `memory/storage-matrix.md` | تنظيف الحزم عبر الأدوات الأصلية (`artisan`, `cargo`, `pnpm`, `docker`) مع بدائل نظام آمنة. |
| `agent` | "تسريع استجابة الوكيل" / "حذف التسجيلات الكبيرة" | `workflows/tune-agent.md` + `memory/agent-tuning.md` | فحص تأخر خطافات العمليات، وحذف إطارات تسجيلات الشاشة، وتحديث مسارات المراقبة. |

## 🛡️ هندسة أمان البيانات والعمليات الخلفية

### 1. مصفوفة أمان المشروعات رباعية المستويات

تصنف أداة `tidyfactor-cleaner` كل ملف أو مجلد وفق 4 مستويات أمان صارمة:

| المستوى | الفئة | الأمثلة | السياسة المطبقة |
|---|---|---|---|
| **المستوى 1** | كاش مؤقت مستهلك | `Cache_Data`, `GPUCache`, `.next/cache`, `~/.npm/_cacache` | **حذف آمن وفوري**: يُعاد بناؤه تلقائياً دون أي تدخل يدوي. |
| **المستوى 2** | أرشيفات وحزم مكررة | ملفات التثبيت القديمة `.exe` / `.msi`، نسخ النسخ الاحتياطي `.zip` | **يتطلب مراجعة**: عرض العمر والحجم والتأكيد قبل الحذف. |
| **المستوى 3** | مجلدات التبعيات القابلة للتثبيت | `node_modules/`, `vendor/`, `.venv/` | **يتطلب ملف قفل**: لا يُحذف إلا بوجود `package-lock.json` أو `composer.lock`. |
| **المستوى 4** | **بيانات محصنة غير قابلة للمساس** | **`Login Data`, `Cookies`, `.env*`, `.git/`, قواعد البيانات, `.gguf`, `.safetensors`** | **محظور قطعياً**: لا يصدر أي أمر حذف لهذه الملفات تحت أي ظرف. |

## 🏛️ منهجية وحوكمة مهارات TidyFactor

تجتاز مهارة `tidyfactor-cleaner` جميع **القواعد الهيكلية الـ 14** الصادرة عن معيار [`tidyfactor-skill-architect`](https://github.com/TidyFactor/Skill-Architect):

1. ✅ **انضباط التوجيه (Dispatcher Discipline)**: يقتصر `SKILL.md` على التوجيه (~350 رمزاً).
2. ✅ **مسار واحد = مخرج واحد (One Workflow = One Outcome)**: لكل مسار عمل مخرج محدد مع قائمة تحقق.
3. ✅ **الذاكرة التشغيلية النقية (Operational Memory)**: جداول ومصفوفات خالية من الحشو الإنشائي.
4. ✅ **الهيكل المسطح الخالي من الفراغات**: عدم وجود مجلدات أحادية الملفات.
5. ✅ **فصل الفلسفة عن التنفيذ**: عزل شروحات التسويق عن الأوامر التقنية.
6. ✅ **نمو مبرر بالأدلة**: لا يُضاف أمر إلا بمرحلة واضحة من دورة حياة محطة العمل.
7. ✅ **أمان وحصانة الهويات**: حماية تامة للجلسات وكلمات المرور والمستويات الأربعة.
8. ✅ **توافق كامل بين الأنظمة**: أداء متطابق 100% عبر Windows وmacOS وLinux.
9. ✅ **سلامة الترويسات (YAML Frontmatter)**: تنصيص مزدوج ومتوافق قياسياً.
10. ✅ **إعلان صلاحيات الأدوات**: تحديد نطاق التدخل بوضوح ودقة.
11. ✅ **تحديث الذاكرة بالتواريخ**: توثيق زمني مستمر لكل ملفات الذاكرة.
12. ✅ **الفصل بين المهارة والـ MCP**: المعرفة داخل المهارة والحالة الحية في الأدوات.
13. ✅ **التوثيق ثنائي الطبقات متعدد اللغات**: توثيق فني أصيل مع ترجمات دولية متقنة.
14. ✅ **الاستشعار التلقائي أولاً (Auto-Sensing First)**: صفر أسئلة للمستخدم حول النظام أو المسارات.
