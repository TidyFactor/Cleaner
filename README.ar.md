## 🎯 القيمة الاستثنائية للمطورين

أدوات التنظيف التقليدية غير مخصصة للمطورين: فهي لا تدرك تعاقب إصدارات إضافات المحررات، وتعجز عن التعامل مع العمليات الخلفية العالقة، أو تخاطر بحذف جلسات المتصفح وكلمات المرور.

يقدم `tidyfactor-cleaner` حلاً حتمياً ومتدرجاً مبنياً على حالات استخدام دقيقة:
- **تشخيص فوري دون تجميد القرص**: فحص ذكي وسريع باستخدام روبوكوبي وأوامر النظام يمنع استهلاك الذاكرة عند فحص المسارات العميقة.
- **إزالة التكرار من إضافات المحررات**: كشف الإصدارات المتقادمة من الإضافات وحذفها، وإلغاء إقفال العمليات العالقة (`codex-code-mode-host`, `kilo`) بأمان، وتفريغ حزم VSIX المتراكمة.
- **عزل آمن لكاش المتصفحات متعددة الحسابات**: تفريغ كاش الويب والأكواد المجمعة ومعالجات الرسوميات دون أي مساس بكلمات المرور أو الجلسات النشطة أو المفضلة.
- **تسريع وكلاء الذكاء الاصطناعي**: فحص الخطافات (`hooks.json`) لإلغاء أي بطء في الاستجابة، وحذف آلاف إطارات تسجيلات المتصفح المؤقتة، وضبط مستشعرات فحص الملفات (`watchers`).
- **تنظيف شامل لأطر العمل والمشروعات (Universal Framework Hygiene)**: تفريغ كاش أطر العمل الحديثة (Next.js, Vite, Nuxt, Laravel, Symfony, WordPress) وحاويات Docker ومديري الحزم المعاصرة (PNPM, Bun, Yarn) بنمط استدعاء الأدوات الأصلية أولاً.

## 🛡️ قواعد الأمان غير القابلة للتفاوض

1. **حماية مطلقة للهويات**: ملفات `Login Data` و`Cookies` و`Bookmarks` و`Preferences` محمية ولا يتم المساس بها نهائياً.
2. **الاستكشاف الذاتي أولاً**: صفر أسئلة للمستخدم حول نظام التشغيل أو المسارات؛ يتم الكشف عنها آلياً.
3. **لا حذف بدون استئذان**: عرض أرقام دقيقة وحسابات واضحة قبل أي عملية حذف.
4. **حماية أصول المشروعات والذكاء الاصطناعي**: حظر قاطع لحذف نماذج وأوزان الذكاء الاصطناعي المحلية (`.gguf`, `.safetensors`)، وأسرار البيئة (`.env`)، والكود وقواعد البيانات.
